Drag a tab to a group's edge to split the window, search the whole vault, and zoom with Ctrl +/−.

## Splitting by dragging

Drag a tab over a group and a highlight shows where it will land. The middle adds it
to that group; near an edge the highlight takes that half, and dropping there opens a
**new group on that side** — right edge for columns, bottom edge for rows. Splits nest,
so the layout is no longer limited to the six presets.

- **Empty groups close themselves.** A group that loses its last tab, closed or
  dragged away, disappears and its neighbours take the space.
- `Ctrl+\` moves the active tab into a new group on the right, and `Ctrl+Shift+N`
  one past the last group opens a new one — the way Sublime does it. The tab menu has
  *Split Right* and *Split Down*.
- Rearranging never reloads a group: an open note keeps its caret, scroll and undo
  history.

## Find in Vault

`Ctrl+Shift+F`, or the sidebar's new **Search** tab, searches every note, todo document
and diagram, with match case, whole word and regular expression toggles. Results are
grouped by file; clicking one opens the document and selects the match. Open documents
are searched with their unsaved edits.

## A proper find bar

`Ctrl+F` in a note used to show a row of lowercase words and bare checkboxes. It is
now a find bar in the VS Code mould: `Aa` / `ab` / `.*` toggles inside the field, a
live "3 of 12" count, icon buttons for previous, next and select-all, and a replace row
with **Replace** and **Replace All** (`Ctrl+H` opens it directly).

## Notes

- **Wrapped list items hang.** A long bullet, number or task wraps under its own text
  instead of back under the marker.
- **`---` is drawn through the middle of its line**, not along the bottom.
- **Full-width notes.** *Settings → Note width* chooses between the readable column
  and the whole pane; the command palette toggles it too.
- **Consolas is the default editor font**, ahead of Cascadia Mono.

## Sidebar

- Folders **start collapsed**, and a new button collapses them all again.
- Opening a file reveals it in the tree. Filtering shows matches inside closed
  folders and hides folders with none.

## Zoom

`Ctrl+=` / `Ctrl+-` / `Ctrl+0` now zoom the whole window, as in VS Code or a browser,
and `Ctrl++` and the numpad keys work too. They used to change only the note font size,
which is still in Settings and the command palette.

## Fixes

- **`Ctrl+Shift+1…9` works.** The shortcut read the character the key produced, and
  with Shift held that is `!`, `@`, … rather than a digit, so moving a tab to a group
  from the keyboard never fired.
- **The outline's headings jump to the heading in Live and Source**, not only in plain
  text.
- Dragging a horizontal divider shows the up-down resize cursor.
