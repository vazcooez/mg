Headings fold, and copying a list gives you the list rather than its markup.

## Sections collapse by heading

A heading owns everything below it up to the next heading of the same or higher rank,
so folding `## Design` takes its prose and its `###` subsections with it and stops at
the next `##`.

- **Hover a heading and a ▾ appears** in the margin. Click it and the section closes,
  leaving a `⋯` chip on the heading that opens it again.
- **The arrow lives in the left padding**, not in a gutter, so it never shifts the
  heading text sideways when it appears.
- **A collapsed heading keeps its arrow showing.** A section that hid itself silently
  would be a section you never found again.
- Headings with nothing under them have no arrow, and a `#` inside a fenced code block
  is code, not a heading.

| | |
|---|---|
| `Ctrl+Shift+[` / `Ctrl+Shift+]` | Fold / unfold the section at the caret |
| `Ctrl+Alt+[` / `Ctrl+Alt+]` | Fold / unfold every section |

Folding works in **Source** as well as **Live**, and it is window state like sort order
and zoom: it never marks the buffer unsaved, and a folded note saves exactly as it reads.

## A copy yields what you could see

1.7.0 drew list markers instead of typing them, but a copy still handed over the raw
markdown. It no longer does: `- ` and `- [ ] ` stay behind and only the words come out,
with the indentation that tells a nested item from a top-level one.

Fenced code is left alone, and the document itself is untouched — copying in **Source**
still gives you the raw form, marker and all.

## Fixes

- **Renaming a file in the sidebar kept its kind.** It used to coerce everything that
  was not a `.mgtodo` to `.md`: `Flow.mgdiagram` came back as a note whose next save
  wrote diagram JSON into a markdown file, and `logo.png` became `banner.png.md`.
- **Undo no longer rewinds a save.** Undoing back past a `Ctrl+S` used to restore the
  buffer's old relationship with disk as well as its old text, and the stale timestamp
  made the next vault event look like an external edit — which quietly replaced the
  buffer with the file. Undo now moves the content back and nothing else: the file stays
  saved, and the buffer simply shows as unsaved again.
