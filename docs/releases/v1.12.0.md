Calendar blocks can now be removed without a detour through the tree.

## `Delete` removes the selected block

Select a block and press `Delete` (or `Backspace`), as on the matrix and in the tree.
It asks first, and what it removes goes to the document's trash rather than being
destroyed — **Trash** has it if you want it back.

A `Delete` aimed at text in the inspector stays with the text: the key only reaches the
calendar when nothing is being typed into.

## Right-click a block

| | |
|---|---|
| **Mark done** | or back to scheduled, if it already is |
| **30m · 1h · 2h** | the lengths you actually reach for |
| **Repeat every day / weekday** | or **Stop repeating**, on a block that already does |
| **Take off the calendar** | drops the time and keeps the item |
| **Delete** | to the trash, after a confirmation |

Deleting a repeating block says so before it goes: a repeat is one item standing in for
a whole series, so the prompt tells you every occurrence goes with it rather than
letting a keystroke meant for one block empty the series quietly.

Right-clicking **empty grid** offers a new item at that time.

Also fixed: right-clicking a block used to start dragging it, because the block took
any button as the start of a move. Only the primary button drags now.
