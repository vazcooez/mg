The note editor learns Sublime Text's editing: multiple cursors, its keys, Mariana colours and a minimap.

## Multiple cursors

The editor could only ever hold one selection, so `Ctrl+D`, `Ctrl+Click` and column
selection all quietly collapsed back to a single cursor. They now work as they do in
Sublime:

- **`Ctrl+D`** selects the word, then adds its next occurrence; **`Alt+F3`** selects
  every occurrence at once.
- **`Ctrl+Click`** adds a cursor, **`Alt+drag`** makes a column selection, and
  **`Ctrl+Alt+↑/↓`** adds a cursor on the line above or below.
- **`Ctrl+Shift+L`** splits a selection into one cursor per line; `Escape` goes back
  to one.

## Sublime's editing keys

| | |
|---|---|
| `Ctrl+Shift+D` | Duplicate the line, or the selection |
| `Ctrl+Shift+↑/↓` | Move the line |
| `Ctrl+Shift+Enter` | New line above |
| `Ctrl+J` | Join lines |
| `Ctrl+G` | Goto Line |
| `Ctrl+R` | Goto Heading |

`Ctrl+L`, `Ctrl+Shift+K`, `Ctrl+Enter` and `Ctrl+/` behave as Sublime's do. Brackets
and quotes close themselves, and matching brackets are outlined. Goto Anything takes
Sublime's operators too: `:42` for a line, `@name` for a heading.

`Ctrl+Shift+D` used to toggle the theme; that is `Ctrl+K Ctrl+T` alone now. Reloading
the window moves from `Ctrl+R` to `Ctrl+Alt+R`.

## Mariana colours

Notes are coloured with Mariana, Sublime Text's default scheme: headings blue, bold
orange, italics violet, code green, links teal, list markers red. The dark editor
background is Mariana's own. Light mode gets the same hues darkened to read on white.

## Minimap and line numbers

- A **minimap** runs down the right edge of every note: the whole document in
  miniature, the visible part outlined. Click to jump, drag to scroll. It can be
  turned off in *Settings → Minimap*.
- **Source mode has line numbers**, with the text beside them rather than centred.
  Live preview keeps its reading layout.
- The status bar reads **Line 12, Column 5**, or how much is selected.

## Sidebar

**Drag the sidebar's edge to resize it.** The width is remembered across restarts;
double-click the edge to reset it.
